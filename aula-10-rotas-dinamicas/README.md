# 📚 Aula 10 — Rota Dinâmica com API de Jogos

## 📌 Sobre o projeto

Projeto desenvolvido durante as aulas de **Programação Back-End**, utilizando o framework **NestJS**.

Nesta atividade, foi desenvolvida uma **rota dinâmica** integrada a uma **API de jogos**, permitindo realizar consultas utilizando parâmetros informados na URL.

---

## 🎯 Objetivo

Praticar a criação de **rotas dinâmicas** utilizando **NestJS**, compreendendo como receber parâmetros através da URL e utilizá-los para realizar consultas de jogos.

Durante a atividade, foram trabalhados conceitos de:

- 🎮 **API de jogos**
- 🌐 **Rotas dinâmicas**
- 🔗 **Parâmetros de rota**
- 📡 **Requisições HTTP**
- ⚙️ **Controllers**

---

## 🛠️ Tecnologias utilizadas

- **Node.js**
- **NestJS**
- **TypeScript**
- **API de Jogos**

---

## 🎮 Rota dinâmica

A aplicação utiliza uma rota dinâmica para realizar consultas de jogos através de um identificador.

O parâmetro informado na URL é utilizado para identificar o jogo que será consultado.

---

## 🔄 Funcionamento

A aplicação recebe o identificador do jogo através da URL e utiliza esse parâmetro para realizar a consulta na **API de jogos**.

Dessa forma, a mesma rota pode ser utilizada para consultar diferentes jogos, de acordo com o identificador informado.

---

## 📖 Aprendizado

Com esta atividade, foi possível compreender o funcionamento das **rotas dinâmicas no NestJS** e como utilizar **parâmetros de rota** para realizar consultas específicas.

Também foi possível praticar a integração com uma **API de jogos**, trabalhando com requisições HTTP e desenvolvendo uma aplicação mais dinâmica.
